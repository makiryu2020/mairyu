# 電解質モニター

酸塩基平衡（Boston法＋Stewart法）と電解質を、1時点ごとに解析し、経過を監視する試作ツールです。
「酸塩基電解質ツール_引き継ぎまとめ」§13 の次のステップのうち、(iv) Tier 1 変数と派生値の追加と、(vi) 時系列層を最小構成で実装しています。

> 臨床意思決定の「支援」を目的とした試作です。医療機器としての検証・承認は受けていません。

## ファイル

| ファイル | 内容 |
|---|---|
| `core.js` | 計算コア。UI を持たない純粋関数で、ブラウザでは `window.EMCore`、Node では `require` で使う |
| `core.test.js` | 単体テスト。`node --test electrolyte-monitor/core.test.js` で実行する |
| `index.html` | 画面（推移チャート・解析・アラート・入力・設定・JSON の入出力） |

## 計算内容

- **Boston法**：AG、アルブミン補正AG（Figge 1998）、ΔΔ、代償の予測式（Winter式 ほか）、一次障害と合併障害の分類（ヒューリスティック）
- **Stewart法**：SIDa、SIDe（Figge 簡易式）、SIG = SIDa − SIDe（正の値は未測定陰イオンを示す標準の符号。引き継ぎまとめ §9-1 の修正点）
- **BE 分解**（Story 2004）：Na–Cl、アルブミン、乳酸、その他の未測定陰イオン
- **派生値**：補正Na（係数 2.4 と 1.6 を切り替え可能）、計算浸透圧、浸透圧ギャップ、Payne の補正Ca、Na で補正した Cl
- **入力値の整合性チェック**：入力した HCO₃⁻ と、pH・pCO₂ から Henderson–Hasselbalch 式で計算した値を比べる
- **時系列**
  - 低Na血症の補正速度：24時間の範囲内で最も低い Na からの上昇幅を計算し、上限 10 mmol/L/24h（高リスク例では 8）と比べる。高血糖がある場合はグルコースで補正した Na を使う
  - RCV（基準変化値）＝ √2 × Z × √(CVA² + CVI²) を超える変化に印を付ける
  - K の急変、補正AG の正常化、最新時点の重大所見をアラートとして表示する

## 未確認の値（要確認）

- CVI は EFLM Biological Variation Database の値を検索要約で得たもの（Na 0.5、K 4.1、Cl 1.1、Ca 1.8、Mg 2.9、P 7.8 %）。原典での確認が必要
- CVA の既定値は「望ましい分析精度」として 0.5×CVI を仮に置いている。自施設で実測した CV に置き換えること
- 総Ca・Mg・グルコースの基準範囲、高K の中等度・軽度の区分、低K（2.5 未満）・低P（1.0 未満）・イオン化Ca（0.9 未満）の重症度の目安、高Ca の重症度区分は記憶に基づく。画面上にもその旨を表示している
- K 急変アラートの閾値（6時間以内に 1.0 mmol/L 以上の変化）は根拠文献のない暫定値

## データの保存

記録は、そのブラウザの localStorage だけに保存されます。別の端末で続けるときは、画面下部の「データの書き出し・読み込み」から JSON をコピーして移してください。氏名や ID など個人を特定できる情報は入力しないでください。
